## 〇、一句话结论

## 二、P2 健壮性加固（8 组，本轮全部完成 ✅）

### 组 1：orchestrator / finalize 资源生命周期
- `pdf_task` 包 try/finally：磁盘写入抛错时任务仍被 reap（不再泄漏 "Task exception never retrieved"）。
- `write_split_markdown_sidecars` 的 `unlink()` 补 `missing_ok=True`（并发清理竞态）。
- manifest `pdf_path` 仅在下载**成功**后写入（旧逻辑提前赋值、失败仅 warning，batch 汇总拿到幻影路径）。
- `_filter_sections`/`_setup_output_dir` 抛错时 `tex_task` 补 cancel+await（多条异常路径泄漏）。

### 组 2：network/http
- `close_http_client` 同时重置 `_rate_lock`/`_rate_next_slot`——旧逻辑第二次 `asyncio.run` + 开启限速即抛 "bound to a different event loop"；补跨 loop 回归测试（`acquire_rate_slot` 此前**零测试**）。
- `get_http_client` 重建时尽力关闭旧 client 连接池（有运行 loop 时调度、同步上下文交给 GC）。
- **删除显式 proxy 读取**（`HTTP_PROXY or HTTPS_PROXY` → `kwargs["proxy"]`）：httpx `trust_env` 本就处理代理且尊重 `NO_PROXY`，显式覆盖反而丢弃 NO_PROXY 语义。

### 组 3：毒化缓存自愈
- `fetch.py` 占位页守卫命中缓存时 `unlink` 后重取——旧版工具写入的占位页缓存此前会在 TTL 内（默认 24h）**每次运行都炸**，只能手工清缓存。补回归测试。

### 组 4：arxiv_api
- 重试循环收敛到 `network/retry.request_with_retries`：404 → None（预期）、不可重试 4xx 不再满重试、异常不再 `except: pass` 吞掉。
- 删除 `_merge_metadata` 中 elif 恒假的 30 行作者匹配合并死代码。
- `_generate_bibtex` 的 `authors[0]["name"]` 可为 None（Atom feed 实际出现）→ TypeError → 整条 entry 被宽 except 静默降级；改取首个非 None 名。

### 组 5：transforms 顺序与编号（本轮最重要的一组）
- `build_default_pipeline` 排序改为 `SectionNumberingPass`(latex) → `SectionFilterPass` → `NumberingPass` → `FigureReorderPass`。旧顺序下 filter 先于 struct_id 唯一赋值点运行，`--sections sec_2_1` **静默无效**（docstring 声称支持）；"过滤节不编号"意图由"被滤节连同编号前缀一起删除"保持（`normalize_section_title` 剥前缀，标题匹配不受影响）。
- `SectionNumberingPass` 加 seen-set：unnumbered 节子节复用父路径导致 `sec_1` 撞车（审计模拟复现）→ 冲突 id 加 `-2` 后缀。
- JSON emitter `_assign_struct_ids` 位置回填先收集已占用 id 再补：此前 unnumbered References（位置 4）被回填 `sec_4`，与 §4 Conclusion 撞车（**golden 重生成时实锤暴露**）。
- `_repoint_section_fragments`：HTML 路径 section anchor 即 ar5iv 元素 id（"S4"），作为权威映射 key；位置推导仅补缺口——过滤导致的错位不再把 `#S4` 链接改写到错误锚点。

### 组 6：emitter / parser / visitor
- Abstract 双重标题：`_extract_abstract` 剥 "Abstract " 前缀（进 metadata/JSON）；`_strip_abstract_heading` 兼顾 heading 块删除与首段文本剥离（实测 `'## Abstract\n\nAbstract This paper...'` → `'## Abstract\n\nThis paper...'`）。
- `_looks_like_name` 机构关键词加 `\b` 词边界：`"mit" in "smith"` 之类子串误杀会把普通作者整名丢掉。
- `_pair_bold_italic_spans` 改为**共享根单次文档序遍历**：旧排序键 `(sourceline or 0, id())` 在片段重解析（sourceline=None）时退化为 id 序 → 全部 bold 排前、第一个 bold 吞掉全部斜体；同行 bold/italic 的配对也借此修正。
- 嵌套有序列表缩进改为按父标记宽（`1. ` 内容列 3 格）：旧 2 空格缩进被 CommonMark 解析为段落延续文本，嵌套结构丢失。
- `ir/visitor.py` figure spec 补 `("images", "inline")`：TextCollector/NodeCounter/内容指纹此前漏掉所有正文图。

### 组 7：JSON emitter
- `emit()` 与 `write_bundle()` 统一在深拷贝上跑 `_assign_struct_ids`——两种序列化结果不再分叉。
- `build_graph` 资产节点按 path 去重（同图多 figure 此前产生重复 node id）。
- **移除恒写空的 `paper.bib.json`**（`_write_bib` + write_bundle 调用点）：假数据文件，无下游消费者；参考文献内容在 split References markdown 中。`PaperBibJson` 模型暂留（标记 Phase D）。

### 组 8：其它
- settings loader 对 user YAML 未知键 `logger.warning`（`extra="ignore"` 保留以容错 env 注入；拼错的 `outputs:` 此前静默不生效）。
- TeX 解压改 `.tmp-<uuid>` 隔离目录 + 成功后原子替换：并发同 id 时一方失败 `rmtree` 不再删掉另一方正在读取的解压目录。
- `query/parser.py` 旧式 ID 支持带点分类：`math.GT/0309136`（arXiv 真实 ID）此前抛 UserInputError。
- real_paper 测试缓存改用 `get_settings().resolved_cache_path()`（尊重 XDG/配置），不再硬编码 Unix 路径。

## 四、系统性根因（写给下一次重构）

1. **防御机制交界处互相拆台**（P1-8、P1-9 同构）：每条降级链的单元测试都绿，但"TeX 429 × HTML 管线""stub × PDF 下载"的组合行为无人验证。→ 已为降级路径建 `test_ingest_degrade.py` + pdf_only 组合用例；后续 pdf_fallback（exit 7）与无图降级也应各补一条端到端。
2. **HTML/LaTeX 双 builder IR 形状不一致**：figure_id 语义（`figure-N` vs `fig:xxx`）、Header level（+1 vs 不加）、citation target 格式、struct_id（HTML 恒 None）各自为政，迫使 emitter/ FigureReorderPass/ split_ir_sections 到处写双路径兼容。本轮的 5c（S-fragment 权威 key）与 4（TableIR.label）是局部缓解，根治需要 builder 输出归一化验收测试。
3. **pass 顺序依赖隐式**：base.py 明言 pass 非幂等、靠"只跑一次"约定；本轮把 filter/numbering 顺序依赖显式写进 `build_default_pipeline` 注释与 `test_canonical_order_preserved`。
4. **资源生命周期收口不严**：lock/task/client 的 teardown 分散各处。建议后续引入统一 async teardown 上下文管理器（`run_async` 已是天然挂点）。
